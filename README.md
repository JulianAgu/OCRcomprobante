Tesseract.js (v6.0.1): Librería de OCR (reconocimiento óptico de caracteres) que permite extraer texto de imágenes y PDF.

pdfjs-dist (v5.4.149): Librería para procesar y renderizar archivos PDF en el navegador.

Testing Libraries:

@testing-library/react, @testing-library/dom, @testing-library/jest-dom, @testing-library/user-event: Herramientas para realizar pruebas unitarias y de interacción en React.

web-vitals: Para medir métricas de rendimiento de la app en producción.

material-UI: Componentes y CSS

Cómo usar la app

Instalar dependencias:

npm install tesseract.js pdfjs-dist


Ejecutar la app:

npm start
